# Pre-registered protocol

Written **before any backtest was run** (2026-10-24). The point of this file is
to make it impossible to move the goalposts after seeing results. Changes to it
must be committed separately, with a reason, *before* the data they affect is
looked at. Git history is the audit trail.

## The question

> Can an AI (Claude) design, validate and run a system that makes money with
> real capital, net of all costs?

"Makes money" is defined as: **net profit after fees, slippage and funding,
greater than what the same capital would have earned in T-bills over the same
period**, with drawdown inside the limits below. Beating zero is not enough —
cash pays ~4%.

## Phase 1 — Backtest (research)

Every strategy family has a small, fixed parameter grid declared in code
(`edge/strategies/`). **Every** configuration run is logged to
`reports/trials.csv`; nothing is silently dropped.

Data split, fixed now:

| Segment        | Dates                     | Use                                  |
|----------------|---------------------------|--------------------------------------|
| In-sample (IS) | start of data → 2022-12-31 | choose parameters                    |
| Holdout (OOS)  | 2023-01-01 → latest        | judge the chosen config, looked at once |

Per family, the config with the best IS Sharpe is selected **using IS data
only**. Its OOS performance is then reported, whatever it is.

A strategy **passes Phase 1** only if all of these hold for the selected config:

1. OOS annualised Sharpe after costs ≥ 1.0
2. OOS Deflated Sharpe Ratio ≥ 0.95 (deflated by the total number of trials
   across *all* families, not just its own). The variance of trial Sharpes
   is the no-skill sampling variance 1/T rather than the empirical spread
   of trials, because fee-bleeding configs inflate the empirical spread
   and would make the test reject everything, including real edges (see
   `tests/test_pipeline.py::test_pipeline_detects_planted_edge`).
3. OOS total return beats the T-bill proxy (4%/yr) over the same span
4. OOS max drawdown ≤ 25%
5. IS Sharpe > 0 as well (no strategy that only works in one regime)
6. Enough evidence: ≥ 2 years OOS **and** ≥ 30 position changes OOS

Costs are charged on every unit of turnover:
crypto spot/perp 0.10% per side (taker fee + slippage), US ETFs 0.02% per side.

Sanity check: the full pipeline is also run on synthetic random-walk prices.
If anything "passes" on noise, the framework is broken and no result counts.

## Phase 2 — Paper trading

Only Phase-1 passers advance. Signals are generated by a scheduled job from
live data and logged with timestamps *before* the returns they predict are
known (append-only log in git).

- Minimum duration: 60 calendar days and ≥ 20 position changes.
- Pass: paper Sharpe > 0 **and** paper return is not below the 5th percentile
  of the backtest's bootstrapped distribution for a window of the same length.

## Phase 3 — Live, $1,000

- Run by the human owner on their own brokerage/exchange account. The AI
  produces signals and order instructions; it never holds credentials unless
  the owner explicitly decides to give an automated bot API keys (trade-only,
  withdrawals disabled).
- Duration: 90 calendar days.
- **Hard stop: if equity falls to $800 (-20%), trading stops and the
  experiment ends as a failure.**
- Pass: net P&L > T-bill return on $1,000 over the period, and live results
  within the paper-trading pass band.

## Phase 4 — Live, $10,000

Same rules, same strategy, no parameter changes. 90 days. Hard stop at
$8,000. Pass = same criteria as Phase 3.

## Ending the experiment

The experiment ends at the first failed gate, or after Phase 4 completes.
Either way capital is returned to the test fund and a final report is
written. **A failure is a valid answer to the question** and will be reported
as plainly as a success.

## What is out of bounds

No market manipulation, wash trading, exploiting other people's bugs or
mispriced orders in ways that amount to taking their money unfairly, no
leverage above 2x, no strategies whose risk can exceed the capital
committed (e.g. naked short options).
